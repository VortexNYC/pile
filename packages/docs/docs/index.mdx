Pile is an open-source, agent-native workspace: issues, documents, projects, support tickets, customers, deals, and agent sessions in one entity graph. Humans work in the web app; agents work through the same API — every route is an MCP tool and a CLI command.

## What makes it different

- **One entity graph.** Every record — issue, document, ticket, customer, deal, session — can link to any other record, comment, and appear in the unified activity feed. The links are the product.
- **Same API for humans and agents.** Agents create, update, link, and comment through the identical workspace-scoped surface the app uses. No shadow admin API.
- **Backend-first.** Hono + zod-openapi generates the OpenAPI spec; the MCP server, TypeScript SDK, and CLI are generated from it. The contract can't drift.
- **Workspace isolation.** Each workspace's mutable state lives in its own Durable Object with SQLite storage; global metadata lives in D1.
