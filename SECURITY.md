# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for security reports.

Email security reports to the maintainers via the contact listed on the
repository owner's profile, or open a private GitHub Security Advisory on this
repository.

Include: affected route/component, reproduction steps, and impact.

## Scope

Pile is a self-hostable Cloudflare Worker. Reports about the code in this
repository are in scope; vulnerabilities in your own deployment's configuration
(domains, secrets, access policies) are yours to manage.
